# Security Policy

## Reporting a vulnerability

Open a GitHub issue in this repository for non-sensitive reports. For a sensitive vulnerability, contact the maintainer privately first through the GitHub profile at https://github.com/musichen instead of posting exploit details publicly.

Please include whether you used the web build (`pnpm start`) or the Tauri desktop app, your macOS version, and steps to reproduce.

## Notes

MonacoTauri is a local editor experiment. Do not open files or workspaces from sources you do not trust, and keep Node, pnpm, and Rust toolchains up to date.
